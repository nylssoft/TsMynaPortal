Getting started and sign-in

The portal is intended for family and friends. On the welcome page, choose Request an account, enter your email address and complete the verification. An administrator must approve your request before you can register. Use the registration code to complete registration.

Choose Sign in and enter your username or email address and password. If prompted, complete the PIN or two-factor authentication step. An existing session may open the desktop directly. Sign out from the navigation menu when finished, especially on shared devices.

Install the portal

You can add the portal to your device for an app-like experience:

  • Android: open the portal in a supported browser. In Firefox, open the three-dot menu and choose Install or Add to Home screen.
  • iPhone or iPad: open the portal in Safari, tap Share, then Add to Home Screen.
  • Desktop: in a supported browser, use its install or add-to-home-screen command if available.

Menus vary by browser and version. The installed portal needs an internet connection to sign in and access account data. Its offline page does not contain your data. Browser and installed-app sessions may be separate. When an update is ready, save your work before choosing Reload; you can postpone the update.

Data protection and account settings

Use Data Protection to view or enter the key used to encrypt and decrypt protected data. Keep a secure copy separate from the portal: if you lose the key, encrypted data cannot be recovered. The data-protection key is separate from your sign-in password and password-backup export passphrase.

In Settings > View settings, select a language and theme and choose which apps appear on your desktop. Account information shows the previous sign-in and storage usage. Under Account settings, manage your profile, email, password, stay-signed-in setting, PIN, two-factor authentication and password-reset option. Review the confirmation carefully before deleting an account and its data.

Desktop tools

Open the desktop after signing in and select a tool. Use the plus icon to add an item, select an item to view or edit it, and save changes. Use search where available.

  • Notes: create and edit notes. The header icons switch between sorting by name or last modified and ascending or descending order; the browser remembers the choice.
  • Diary: use the arrows to change month, then select a day to view or edit its entry.
  • Contacts and birthdays: add and edit contacts and their details; the birthdays view shows upcoming birthdays from your contacts.
  • Passwords: add and edit website login entries. Use the separate encrypted backup described below to keep a copy outside the portal.

Documents and sharing

Use the file and folder icons to upload files or create folders; open folders to browse. Select a file to preview supported images, PDFs, text or Markdown. Markdown can be viewed as rendered text or source; images are not loaded in Markdown previews.

Turn on selection mode to select items for renaming, moving, deleting or downloading. One file keeps its name; multiple items or a folder download as a ZIP including nested and empty folders. Downloaded private files are decrypted, so protect the resulting ZIP. Large downloads are assembled in browser memory.

Users with the administrator role can set an owned folder to private, family or public, and edit shared Markdown files. Family access requires the family role; public files are accessible without signing in. New files uploaded directly into shared folders are unencrypted. Changing visibility does not change existing files or subfolders; new subfolders are private. Moving items does not change their visibility or encryption. Private encrypted Markdown cannot be edited with the shared-file editor.

Appointments, weather and games

Appointments: add a description, participants and possible days, then save. Open the appointment and share its voting link. Participants choose their name and indicate availability; the calendar shows the votes. A participant cannot be removed once voting has started.

Weather: search for a city and choose a location if needed. Scroll horizontally through hourly cards or switch to the seven-day view. Times use the city's time zone. The last selected location is remembered and a fresh forecast is requested when you reopen Weather. Weather data is provided by Open-Meteo.

Games: select a game from the navigation menu to open it. Available games depend on the portal deployment.

Back up and restore

In Settings > Export data, select notes, diary, contacts, passwords or documents and start the export. Each ZIP contains one type. Use the download link if the automatic download is blocked, and verify that the browser saved the file. Only password exports are encrypted; all other exports can contain readable personal data. Store every backup securely.

For passwords, choose and confirm an export passphrase of at least 12 characters. Keep it safe: it cannot be recovered. It is separate from your data-protection key and sign-in password.

To restore, select Settings > Import data, choose the data type and its ZIP, and start the import. A data-protection key is required; password imports also require the export passphrase. Confirm if the destination already contains data. Notes, contacts and passwords are added and repeated imports can create duplicates. Existing diary dates are skipped. Documents are restored as private; conflicting files are renamed. Imports can partially complete if an error occurs: check the results before retrying and do not import concurrently from multiple sessions.

Imports allow up to 10,000 entries and 512 MiB for the ZIP and extracted data; password backups are limited to 16 MiB. Large archives can use substantially more browser memory.

Open a password backup separately

Choose Open password backup on the welcome page or in the password export view, or open the password-backup reader over HTTPS. Select the ZIP and enter its export passphrase. The reader needs no account and decrypts locally without uploading or saving the unlocked data. Lock the view when finished; it also locks after two minutes of inactivity. Copied passwords may remain on the clipboard.

Alternatively, on Windows use Myna Password Manager to import the ZIP into an open local repository. Save the repository after import; repeated imports create duplicates.

Administration

The Administration menu is available to users with the usermanager role. In Registration requests, approve or reject requests and optionally send an email; approval shows the registration code. In Registered users, review accounts and usage, change quotas and roles, allow or block sign-in, unlock accounts, or delete selected accounts after confirmation. If a request or notification fails, refresh and check the current status before retrying.

Troubleshooting and privacy

  • If sign-in fails, check your credentials and any PIN or two-factor prompt. The login page offers a password-reset request when enabled for your account.
  • If protected data cannot be decrypted, check the key under Data Protection. A lost key cannot be recovered by the portal.
  • If a backup cannot be opened, select the original ZIP and check the export passphrase. Check partial imports before trying again.
  • Weather searches are sent to Open-Meteo. Account operations use the configured server; public and shared documents have the visibility described above.

Erste Schritte und Anmeldung

Das Portal ist für Familie und Freunde gedacht. Wähle auf der Startseite Konto beantragen, gib deine E-Mail-Adresse ein und schließe die Überprüfung ab. Ein Administrator muss den Antrag genehmigen, bevor du dich registrieren kannst. Schließe die Registrierung mit dem Registrierungscode ab.

Wähle Anmelden und gib deinen Benutzernamen oder deine E-Mail-Adresse und dein Passwort ein. Gib bei Aufforderung die PIN oder den Zwei-Faktor-Code ein. Eine bestehende Sitzung kann den Desktop direkt öffnen. Melde dich auf gemeinsam genutzten Geräten nach der Nutzung über das Navigationsmenü ab.

Portal installieren

Du kannst das Portal für eine App-ähnliche Nutzung zu deinem Gerät hinzufügen:

  • Android: Öffne das Portal in einem unterstützten Browser. Öffne in Firefox das Drei-Punkte-Menü und wähle Installieren oder Zum Startbildschirm hinzufügen.
  • iPhone oder iPad: Öffne das Portal in Safari, tippe auf Teilen und anschließend auf Zum Home-Bildschirm.
  • Desktop: Nutze in einem unterstützten Browser den Befehl zum Installieren oder Hinzufügen, falls verfügbar.

Die Menüs hängen von Browser und Version ab. Das installierte Portal benötigt eine Internetverbindung für Anmeldung und Kontodaten. Die Offline-Seite enthält keine Daten. Browser und installierte App können getrennte Sitzungen verwenden. Speichere deine Arbeit vor Neu laden, wenn ein Update bereitsteht; du kannst das Update verschieben.

Datenschutz und Kontoeinstellungen

Unter Datenschutz kannst du den Schlüssel zum Ver- und Entschlüsseln geschützter Daten anzeigen oder eingeben. Bewahre eine sichere Kopie außerhalb des Portals auf: Bei Verlust lassen sich verschlüsselte Daten nicht wiederherstellen. Der Datenschutzschlüssel ist vom Anmeldepasswort und der Export-Passphrase für Passwortsicherungen getrennt.

Unter Einstellungen > Ansichtseinstellungen wählst du Sprache und Design sowie die Apps für den Desktop. Kontoinformationen zeigen die vorherige Anmeldung und Speichernutzung. In den Kontoeinstellungen verwaltest du Profil, E-Mail, Passwort, angemeldet bleiben, PIN, Zwei-Faktor-Authentifizierung und die Option zum Zurücksetzen des Passworts. Prüfe die Bestätigung sorgfältig, bevor du ein Konto und dessen Daten löschst.

Desktop-Werkzeuge

Öffne nach der Anmeldung den Desktop und wähle ein Werkzeug. Mit dem Plus-Symbol fügst du Einträge hinzu; wähle einen Eintrag zum Anzeigen oder Bearbeiten und speichere Änderungen. Wo vorhanden, kannst du die Suche verwenden.

  • Notizen: Erstelle und bearbeite Notizen. Die Symbole im Kopf schalten zwischen Sortierung nach Name oder Änderungsdatum sowie auf- oder absteigender Reihenfolge um. Der Browser merkt sich die Auswahl.
  • Tagebuch: Wechsle mit den Pfeilen den Monat und wähle einen Tag, um seinen Eintrag anzuzeigen oder zu bearbeiten.
  • Kontakte und Geburtstage: Erstelle und bearbeite Kontakte und ihre Angaben. Die Geburtstagsansicht zeigt kommende Geburtstage aus deinen Kontakten.
  • Passwörter: Erstelle und bearbeite Website-Anmeldedaten. Mit der unten beschriebenen verschlüsselten Sicherung kannst du eine Kopie außerhalb des Portals aufbewahren.

Dokumente und Freigaben

Mit den Datei- und Ordnersymbolen lädst du Dateien hoch oder erstellst Ordner; öffne Ordner zum Durchsuchen. Wähle eine Datei für die Vorschau unterstützter Bilder, PDFs, Text- oder Markdown-Dateien. Markdown kann gerendert oder als Quelltext angezeigt werden; Bilder werden in der Vorschau nicht geladen.

Aktiviere den Auswahlmodus, um Elemente umzubenennen, zu verschieben, zu löschen oder herunterzuladen. Eine einzelne Datei behält ihren Namen; mehrere Elemente oder ein Ordner werden als ZIP mit verschachtelten und leeren Ordnern heruntergeladen. Private Dateien werden für den Download entschlüsselt; schütze die ZIP-Datei. Große Downloads werden im Browserspeicher zusammengestellt.

Benutzer mit Administratorrolle können eigene Ordner auf privat, Familie oder öffentlich setzen und geteilte Markdown-Dateien bearbeiten. Familienzugriff erfordert die Familienrolle; öffentliche Dateien sind ohne Anmeldung zugänglich. Neue Dateien, die direkt in freigegebene Ordner hochgeladen werden, sind unverschlüsselt. Eine Sichtbarkeitsänderung ändert bestehende Dateien und Unterordner nicht; neue Unterordner sind privat. Verschieben ändert weder Sichtbarkeit noch Verschlüsselung. Private verschlüsselte Markdown-Dateien können nicht mit dem Editor für geteilte Dateien bearbeitet werden.

Termine, Wetter und Spiele

Termine: Gib eine Beschreibung, Teilnehmer und mögliche Tage ein und speichere. Öffne den Termin und teile den Abstimmungslink. Teilnehmer wählen ihren Namen und geben ihre Verfügbarkeit an; der Kalender zeigt die Stimmen. Nach Beginn der Abstimmung können Teilnehmer nicht mehr entfernt werden.

Wetter: Suche eine Stadt und wähle bei Bedarf einen Ort aus. Scrolle horizontal durch die Stundenkarten oder wechsle zur Sieben-Tage-Ansicht. Die Zeiten verwenden die Zeitzone des Ortes. Der letzte Ort wird gespeichert und beim erneuten Öffnen eine aktuelle Vorhersage geladen. Die Wetterdaten stammen von Open-Meteo.

Spiele: Wähle im Navigationsmenü ein Spiel aus, um es zu öffnen. Die verfügbaren Spiele hängen von der Portalinstallation ab.

Sichern und Wiederherstellen

Wähle unter Einstellungen > Daten exportieren Notizen, Tagebuch, Kontakte, Passwörter oder Dokumente und starte den Export. Jede ZIP enthält einen Datentyp. Nutze den Download-Link, falls der automatische Download blockiert wird, und prüfe, ob der Browser die Datei gespeichert hat. Nur Passwortexporte sind verschlüsselt; alle anderen Exporte können lesbare persönliche Daten enthalten. Bewahre alle Sicherungen sicher auf.

Für Passwörter wähle und bestätige eine Export-Passphrase mit mindestens 12 Zeichen. Bewahre sie sicher auf; sie kann nicht wiederhergestellt werden. Sie ist vom Datenschutzschlüssel und Anmeldepasswort getrennt.

Zum Wiederherstellen wähle Einstellungen > Daten importieren, den Datentyp und seine ZIP und starte den Import. Ein Datenschutzschlüssel ist erforderlich; für Passwörter zusätzlich die Export-Passphrase. Bestätige, falls bereits Daten vorhanden sind. Notizen, Kontakte und Passwörter werden hinzugefügt; wiederholte Importe können Duplikate erzeugen. Vorhandene Tagebuchdaten werden übersprungen. Dokumente werden privat wiederhergestellt; bei Namenskonflikten werden Dateien umbenannt. Bei Fehlern kann ein Import teilweise abgeschlossen sein: Prüfe das Ergebnis vor einem erneuten Versuch und importiere nicht gleichzeitig aus mehreren Sitzungen.

Importe erlauben bis zu 10.000 Einträge und 512 MiB für ZIP und entpackte Daten; Passwortsicherungen sind auf 16 MiB begrenzt. Große Archive können deutlich mehr Browserspeicher benötigen.

Passwortsicherung separat öffnen

Wähle Passwortsicherung öffnen auf der Startseite oder beim Passwortexport, oder öffne den Passwortsicherungsleser über HTTPS. Wähle die ZIP und gib ihre Export-Passphrase ein. Der Leser benötigt kein Konto und entschlüsselt lokal, ohne die geöffneten Daten hochzuladen oder zu speichern. Sperre die Ansicht nach der Nutzung; nach zwei Minuten Inaktivität wird sie automatisch gesperrt. Kopierte Passwörter können in der Zwischenablage bleiben.

Alternativ kannst du unter Windows mit dem Myna Password Manager die ZIP in ein geöffnetes lokales Repository importieren. Speichere das Repository nach dem Import; wiederholte Importe erzeugen Duplikate.

Verwaltung

Das Menü Verwaltung steht Benutzern mit der Rolle usermanager zur Verfügung. Unter Registrierungsanfragen kannst du Anträge genehmigen oder ablehnen und optional eine E-Mail senden; bei Genehmigung wird der Registrierungscode angezeigt. Unter Registrierte Benutzer kannst du Konten und Speichernutzung prüfen, Limits und Rollen ändern, Anmeldungen erlauben oder sperren, Konten entsperren oder ausgewählte Konten nach Bestätigung löschen. Falls eine Aktion oder Benachrichtigung fehlschlägt, aktualisiere und prüfe den Status vor einem erneuten Versuch.

Probleme und Datenschutz

  • Prüfe bei Anmeldeproblemen deine Zugangsdaten und eine mögliche PIN- oder Zwei-Faktor-Abfrage. Die Anmeldeseite bietet eine Passwort-Zurücksetzung an, sofern sie für dein Konto aktiviert ist.
  • Falls geschützte Daten nicht entschlüsselt werden können, prüfe den Schlüssel unter Datenschutz. Ein verlorener Schlüssel kann vom Portal nicht wiederhergestellt werden.
  • Falls eine Sicherung nicht geöffnet werden kann, wähle die ursprüngliche ZIP und prüfe die Export-Passphrase. Prüfe teilweise Importe vor einem erneuten Versuch.
  • Wettersuchen werden an Open-Meteo gesendet. Kontoaktionen verwenden den konfigurierten Server; für öffentliche und geteilte Dokumente gilt die oben beschriebene Sichtbarkeit.
